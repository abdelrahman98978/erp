# Testing & QA Skill

## Quality Assurance Standards

### 1. Test Coverage Strategy
- Write unit tests for core domain logic, utility functions, and custom hooks.
- Write component integration tests using React Testing Library or Vitest.
- Mock external APIs (like Supabase or REST endpoints) during automated test execution.

### 2. Edge Case Verification
- Always test zero/empty data states, loading states, and error handling branches.
- Verify boundary values and unexpected payload structures.
