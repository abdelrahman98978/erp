# UI/UX & Design System Skill

## Principles of Modern Web Aesthetics

### 1. Visual Excellence
- Use curated, harmonious HSL/Hex color palettes (dark modes, subtle glassmorphism, soft glow effects).
- Use modern Google typography (Inter, Outfit, Roboto) over default system fonts.
- Avoid generic primary colors (plain red, blue, green).

### 2. Layout & Responsiveness
- Implement fully responsive designs (mobile-first, tablet, desktop breakpoints).
- Avoid hardcoding static pixel offsets (+ 12) or arbitrary multipliers when computing dynamic container bounds.
- Use flexbox and CSS grid with proper alignment and spacing tokens.

### 3. Dynamic Interactions & Micro-animations
- Add smooth CSS transitions (`transition: all 0.2s ease-in-out`) for hover states and button presses.
- Use subtle skeleton loaders and loading spinners during asynchronous operations.
